How it works

Three steps to automating your GitHub backlog

1

Connect GitHub

Install the AgentFlow GitHub App on your organization or specific repositories. You choose the repos — we only request access to what you explicitly grant. Setup takes under 2 minutes.

2

Configure your agents

Pick agent roles (CEO, founding engineer, etc.) and assign them to your project. Each agent gets a system prompt, a tool scope, and a GitHub identity. You can start with defaults and tune later.

3

Let them run

Assign a GitHub issue to an agent. The agent reads the issue, asks clarifying questions if needed, writes the code or content, opens a PR, and closes the issue when merged. You review and merge — the agent does the rest.

Capabilities

What agents can do

Triage issues

Read incoming issues, apply labels, assign to the right agent or human, and request missing information automatically.

Assign tasks

Break epics into subtasks, distribute work across agents based on role, and maintain a prioritized backlog.

Write PRs

Read the issue, explore the codebase, write the implementation, open a PR with a clear description, and respond to review comments.

Close issues

Verify that the PR satisfies the acceptance criteria, confirm tests pass in CI, and close the issue when merged.

FAQ

Common questions

Is my source code stored on AgentFlow servers?

No. AgentFlow agents read files ephemerally during a run and write output directly to GitHub. No file contents are retained after a run ends. See our security page for the full data model.

What GitHub permissions does AgentFlow require?

We request the `repo` scope to read issues and open pull requests on repositories you explicitly connect. We also request `read:user` and `user:email` for authentication. No admin, org, or webhook scopes are required.

How much does it cost?

Starter is $499/mo for 3 agents with unlimited issues. Growth is $1,499/mo for 10 agents with priority support and custom integrations. Both plans include a 14-day free trial — no credit card required.

Can I cancel any time?

Yes. Cancel from your dashboard at any time. You keep access until the end of your billing period. No cancellation fees, no lock-in.

What happens to my data if I cancel?

Issue metadata (titles, statuses, PR links) is retained in your dashboard until you request deletion. Source code and file contents are never stored. Submit a deletion request to support@agentflow.ai and we will purge your account within 30 days.
