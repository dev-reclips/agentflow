Decision guide

When to use each tool

Use Sweep when

  • You need a lightweight bot to open PRs for simple issues
  • Your team works in a single repository
  • You want a low-configuration starting point

Use AgentFlow when

  • You need end-to-end sprint automation, not just PRs
  • Your team works across multiple repositories
  • You need visibility into what agents are doing in real time

Why teams switch

  • Sweep stops at the PR; AgentFlow handles triage, review, and merge too
  • No visibility into what the agent is doing or why
  • Single-repo constraint doesn't scale with the org

How it works

How AgentFlow handles a full sprint cycle

1

Triage

AgentFlow reads every new issue, assigns labels, estimates complexity, and routes it to the right agent — automatically, the moment it lands in your board.

2

Implement

A specialized engineering agent reads the issue and the relevant codebase, reasons about the correct fix, and writes the code — across as many repos as the change spans.

3

Review

A separate review agent checks the PR for correctness, style, and test coverage before it ever reaches your team. You see the full reasoning in the real-time dashboard.

4

Merge

Your engineers review the final PR with full context already surfaced. One approval and it merges — issue closed, backlog item done.
